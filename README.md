# BOOKIFY 

**BOOKIFY** is a simple online bookstore website designed for students, parents, and anyone looking for CBC learning materials.The project allows users to browse books by grade level and view basic information such as the book title, description, price, and rating.

## Project Overview

**BOOKIFY** is designed to provide a simple online platform where users can browse educational books based on their grade level.The website presents books from Grade 1 to Grade 6 and provides information such as book titles, subjects, descriptions, ratings, and prices.Users can also filter the displayed books by grade level and switch between light and dark mode.

## Project Goals

The main goals of this project were to:

1. Build a professional online bookstore interface
2. Practice semantic HTML5
3. Practice CSS3 styling
4. Create a responsive, mobile-friendly layout
5. Organize books according to grade level
6. Implement CSS-based book filtering
7. Create a simple dark mode
8. Practice accessibility using labels and alternative text
9. Practice organizing a project for GitHub

## TECHNOLOGIES USED

The following technologies and development tools were used:

- HTML5 – Used to create the structure and content of the website.

- CSS – Used to style the website, create layouts, implement responsive design, and create the filtering system.

- Git – Used for version control.

- GitHub – Used to store and manage the project repository.

- Visual Studio Code – Used as the development environment.

## BUSINESS RATIONALE

### Business Problem

Finding educational books can be difficult when customers have to search through different physical stores or websites.

BOOKIFY is designed as a simple online bookstore concept that makes it easier for users to browse educational books according to the grade level of the learner.

The website provides a clear way for users to view available books, their subjects, descriptions, ratings, and prices.

### Target Audience

The website is designed for:

- Parents looking for educational books for their children
- Students looking for learning materials
- Teachers looking for educational resources
- Schools looking for CBC learning materials
- Customers interested in purchasing educational books

### Business Goals

The main goals of the BOOKIFY website are to:

- Establish a simple online bookstore presence
- Make educational books easy to browse
- Organize books according to grade level
- Clearly display book information and prices
- Provide a simple and accessible user experience
- Create a foundation for a future online bookstore
- Allow the project to be expanded with additional functionality

## BOOK FILTERING

BOOKIFY currently uses HTML and CSS to provide grade-based filtering.

Users can select:

- All Books
- Grade 1
- Grade 2
- Grade 3
- Grade 4
- Grade 5
- Grade 6

The selected grade displays the books belonging to that grade.
